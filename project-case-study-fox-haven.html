🦊 Fox Haven Farm Stand — E-Commerce & POS Web Application

An interactive, responsive Point of Sale (POS) and online ordering platform built for local farm stands, artisanal bakeries, craft breweries, and wineries.

🌟 Project Purpose & Passion

I believe local businesses, agriculture, farm stands, and craft breweries deserve modern, intuitive digital tools that match the quality of their products. This project was engineered to explore how a clean UI and practical workflows can improve in-person and online sales for small producers.

🛠️ Key Features & Workflows

  • Dynamic Inventory Filtering & Search — Category tabs, real-time search filtering, and seasonal zero-result fallbacks.
  • Point of Sale (POS) Basket & Receipt Generator — Real-time subtotal, 7% sales tax calculation, quantity controls, and print-ready thermal receipt layouts.
  • Customer Accounts & Profile Management — Persistent profiles and payment cards managed via browser localStorage.
  • Alcohol Age-Verification (21+) — Automated age calculation from birthdate, mandatory physical ID warnings for deliveries, and verification modals for compliance.
  • Fulfillment & Delivery Radius Check — Pickup/delivery options with 5-digit zip code distance validation and scheduled delivery windows.
  • Customer Loyalty Program — Automatic 10 points per $1 spent on completed checkouts, visible on profiles and headers.

🚀 Tech Stack

  • Frontend: React 18, TypeScript, Vite
  • Styling: Custom CSS inline styles & glassmorphic UI components
  • State & Persistence: React Hooks + browser localStorage
  • Deployment: GitHub Pages (gh-pages)

💻 Local Development Setup

  1. Clone the repository:
git clone https://github.com/levired6/fox-haven-farm-stand.git
cd fox-haven-farm-stand
  1. Install dependencies:
npm install
  1. Start local development server:
npm run dev
  1. Build for production:
npm run build

📝 Demo Login Instructions

When testing the live site, you can either:

  • Click Log In / Sign Up and choose Log In with any email to load a pre-configured demo account with sample cards and loyalty points.
  • Fill out the Sign Up form to test birthdate validation, address loading, and promotion preferences.

Ready for Launch

When you're ready to deploy:

npm run deploy
